# 全窗口重建说明

本图已经从预测实验改为离线全窗口重建。保留原图各事件第 2 折的显示范围，但将该范围内的所有观测都用于拟合，不再划分训练、验证或测试区间。
所有方法使用相同种子列表 [11]，完整窗口的 RMS/总量归一化、相同观测损失、400 次 Adam 更新和最多 0 次 L-BFGS 迭代。网络结构、动力学方程和历史条件保持原实现；TimePINN 保留其原有的因果残差权重。
检查点选择：Minimum complete training objective including physics and history, same rule for all models。曲线均来自模型计算，无人工移线或插值替换。
损失函数：12*(full-window RMS-normalized activity MSE + log1p activity MSE + 0.1*full-window sum-normalized cumulative MSE) + 2.0*physics + 4*history
因此，本图只能比较样本内重建精度，不能支持未来预测性能或泛化优势的结论。
